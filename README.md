# GoldWatch IR — TGJU Gold Monitor

ربات تلگرام برای پایش قیمت هر گرم طلای ۱۸ عیار ایران، اونس جهانی طلا (XAU/USD) و دلار آزاد TGJU؛ به‌همراه تاریخچه و داشبورد فارسی.

## راه‌اندازی

1. در تنظیمات مخزن، از مسیر **Settings → Secrets and variables → Actions** دو repository secret بسازید:
   - `BOT_TOKEN`: توکن ربات تلگرام
   - `CHAT_ID`: شناسه گفت‌وگو یا کانالی که ربات اجازه ارسال پیام در آن را دارد
2. مطمئن شوید GitHub Actions برای مخزن فعال است.
3. از تب **Actions**، گردش‌کار **TGJU Gold Monitor** را باز کنید و یک بار **Run workflow** را اجرا کنید.
4. زمان‌بندی فعلی روی دقیقه‌های 07 و 37 هر ساعت است. GitHub ممکن است اجرای cron را عقب بیندازد یا در شرایط پرترافیک بعضی اجراها را از دست بدهد؛ اجرای دقیق هر ۳۰ دقیقه تضمین‌شده نیست.
5. داشبورد اصلی در فایل `index.html` است. برای انتشار آن، GitHub Pages باید در تنظیمات مخزن فعال و روی شاخه/مسیر مناسب تنظیم شده باشد.

## فایل‌های داده

- `last_price.json`: آخرین وضعیت، آمار روزانه و وضعیت تازگی هر بازار.
- `price_history.json`: تاریخچه نقاط دریافت‌شده؛ مقدار `null` یعنی دریافت آن بازار در آن نوبت ناموفق بوده است.
- `gold_monitor.py`: دریافت قیمت، گزارش تلگرام و ذخیره وضعیت.
- `.github/workflows/monitor.yml`: اجرای خودکار و ثبت تغییرات داده.

قیمت هر بازار فقط زمانی در داشبورد نمایش داده می‌شود که آخرین تلاش برای همان بازار موفق باشد. زمان آخرین دریافت موفق هر بازار جداگانه ثبت می‌شود. فایل‌های قیمت و تاریخچه در این مخزن عمومی‌اند؛ هیچ توکن یا اطلاعات محرمانه‌ای را در آن‌ها قرار ندهید.

## محدودیت‌ها

- قیمت‌ها از منابع ثالث می‌آیند و ممکن است با تأخیر، اختلال یا تغییر ساختار صفحه روبه‌رو شوند.
- اجرای cron در GitHub Actions تضمین دقیق هر ۳۰ دقیقه ندارد.
- آستانه هشدار فعلی `ALERT_THRESHOLD = 0.5` درصد است و تغییر را نسبت به آخرین قیمت موفق ذخیره‌شده می‌سنجد.
- آمار روزانه از نمونه‌های دریافت‌شده در طول روز محاسبه می‌شود و لزوماً سقف/کف رسمی بازار نیست.
- این داشبورد ابزار اطلاع‌رسانی است و تضمین صحت یا به‌موقع بودن قیمت منبع ثالث را نمی‌دهد.

## عیب‌یابی

- اگر اجرای Action شکست خورد، لاگ مرحله **Monitor gold price** را بررسی کنید.
- اگر پیام تلگرام نمی‌رسد، کنترل کنید secretهای `BOT_TOKEN` و `CHAT_ID` درست باشند و ربات مجوز ارسال داشته باشد.
- اگر یک بازار خطا دارد، زمان آخرین موفقیت و پیام خطای همان بازار را در `last_price.json` بررسی کنید.
